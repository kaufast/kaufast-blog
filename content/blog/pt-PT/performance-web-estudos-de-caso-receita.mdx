  - question: "Qual é o impacto real de velocidade de site em receita?"
    answer: "Um segundo de atraso custa 7% de conversões. Para um site que ganha €10.000/mês, isso é €700/mês ou €8.400/ano. Os maiores ganhos vêm de otimizar imagens (40-50% redução), reduzir JavaScript (30-40% redução), e usar CDN (50-70% redução em latência geográfica)."
  - question: "Quanto custa otimizar velocidade vs o quanto poupa?"
    answer: "Otimizações de velocidade típicas custam €2.000-€10.000 uma vez. Ganho mensal médio é €500-€1.500 em receita adicional. ROI médio é 4-6x no primeiro ano. Depois é lucro puro."
  - question: "Que tipo de site vê maior retorno de otimização de velocidade?"
    answer: "E-commerce (onde cada segundo é receita), SaaS (onde performance é feature), e sites de serviço com alta conversão. Blogs veem menos impacto porque conversão é lower-intent. Mas velocidade ainda afeta rankings do Google uniformemente."
